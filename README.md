([Read more](/details/formatjs.md)) `Open Source` `Free Plan` `JavaScript` `React` `Formatting`

## Open-Source TMS

- [GlotPress](https://glotpress.org/) - GlotPress is an open-source, web-based translation management system built as a WordPress plugin. - [Pontoon](https://pontoon.mozilla.org/) - Pontoon is Mozilla's open-source translation management system for web and desktop applications. It supports in-context localization and integrates with version control systems. The platform can be self-hosted and is free to use. - [Tolgee](https://tolgee.io/) - Tolgee is an open-source localization platform that enables in-context translation directly within applications. ([Read more](/details/tolgee.md)) `Open Source` `Self-Hosted` `In-Context` `API` `Freemium`
- [Weblate](https://weblate.org/) - Weblate is a web-based translation management system with version control integration and support for many file formats. It can be self-hosted or used as a cloud service, and is widely used by open-source projects. The core software is free and open source, with paid hosting available. ([Read more](/details/weblate.md)) `Open Source` `Self-Hosted` `Free Plan` `API` `Version Control`
